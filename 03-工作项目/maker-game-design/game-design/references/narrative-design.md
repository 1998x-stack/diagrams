# 叙事设计 / 世界观 / 角色塑造 / 剧情架构

---

## 1. 游戏叙事的独特性

游戏叙事根本上不同于电影和小说：**玩家是主动参与者，而非被动接受者**。

### 叙事三种形态

| 形态 | 定义 | 代表作 | 设计主导者 |
|------|------|--------|---------|
| **嵌入式叙事（Embedded）** | 设计者预先写好的故事 | 最后生还者、FF系列 | 策划/编剧 |
| **涌现式叙事（Emergent）** | 玩家行为产生的故事 | EVE Online、我的世界 | 机制本身 |
| **表达式叙事（Expressive）** | 玩家创作自己的故事 | D&D类、The Sims | 玩家自己 |

**三种形态的结合才是游戏叙事的潜力所在**。《荒野大镖客2》：强大的嵌入叙事 + 开放世界的涌现 + 玩家可选择的表达。

### 游戏叙事的致命弱点

**叙事与玩法的冲突（Ludonarrative Dissonance）**：
- 剧情说主角重视人命，玩法上却是一个大规模杀手
- 过场动画里主角虚弱，玩法里无比强大
- 这种冲突会打破沉浸感，让玩家觉得"故事是表演"

消除方法：**让玩法本身讲故事**，而不是靠过场动画叙事。

## 2. 世界观构建

### 四个层次模型

```
第一层：物理法则层
  ↓ 这个世界的基本运行规律是什么？
  → 魔法怎么运作？科技水平？物理规律有无例外？

第二层：历史文化层
  ↓ 这个世界经历了什么？人们相信什么？
  → 重大历史事件？宗教/信仰体系？文化习俗？

第三层：权力结构层
  ↓ 谁掌权？为什么？存在什么核心冲突？
  → 政治派系？阶级矛盾？种族关系？核心张力在哪？

第四层：日常生活层
  ↓ 普通人的一天是什么样的？
  → 吃什么？住在哪？有什么娱乐？担心什么？
```

**关键原则**：玩家不需要知道所有细节，但他们会感受到世界是否"真实存在"。当世界观自洽，玩家会自发填补细节——这是 IP 诞生的起点。

### 冰山理论在世界观中的应用

```
玩家能看到的（20%）：
  主线剧情、主要角色、核心地区

隐藏在水面下的（80%）：
  大量历史细节、次要角色的完整背景故事
  玩家不会主动触发的旁白、环境叙事
  设定集里存在但游戏里只有线索的内容
```

水面下80%的内容即使玩家看不到，他们也能感知到世界的"厚度"。那些说"这个游戏世界感觉很真实"的玩家，感受到的正是水面下的分量。

### 世界观的一致性护城河

一旦确立，以下规则必须不惜代价维护：
1. **因果一致性**：发生的事有原因，行动有后果
2. **规则一致性**：同样的规则对所有角色同等适用（包括主角）
3. **文化一致性**：不同文化背景的角色有不同的行为逻辑
4. **历史一致性**：过去的事件对现在有影响

## 3. 角色塑造

### 立体角色的三个维度

```
表层（Façade）：
  外貌、言行举止、社会角色
  → 玩家第一时间感知的部分

中层（Desires）：
  明确的愿望与目标
  → 驱动角色行动的动力

深层（Wound）：
  隐藏的创伤、内心矛盾、真实动机
  → 角色"真实"感的来源
```

浅薄的角色只有表层。让玩家"爱上"一个角色，需要深层的裂缝和矛盾。

### 玩家角色（PC）设计的特殊性

玩家角色不是小说主角，因为**玩家需要投射自我**：

| 策略 | 设计形式 | 适用场景 |
|------|---------|---------|
| **空白主角** | 极少台词，外貌可定制 | 沉浸式RPG（上古卷轴）|
| **强设定主角** | 完整背景和性格 | 剧情驱动游戏（最后生还者）|
| **选择型主角** | 玩家决定性格走向 | 对话选择游戏（巫师3）|
| **多主角** | 视角在多个角色间切换 | 史诗叙事（GTA5）|

### NPC 设计的层次

```
装饰NPC（路人甲）：维持世界感即可，不需要深度
功能NPC（商店、传送）：清晰、易用，不阻碍流程
情节NPC（任务给予者）：有动机逻辑，不能是纯工具
核心NPC（伙伴/反派）：需要完整的角色设计
```

优秀 NPC 的标志：**他们有自己的生活，玩家只是打扰了它**。

## 4. 剧情架构

### 三幕式结构的游戏化改造

```
Act 1 建立（Setup）         → 0-15%游戏时长
  引入世界、主角、核心冲突
  承诺玩游戏的体验目标
  给玩家一个"为什么继续"的理由

Act 2 对抗（Confrontation） → 15-85%游戏时长
  主角面对一系列障碍
  事情越来越复杂/危险
  中点（Midpoint）：重大转折，玩家重新定义目标

Act 3 解决（Resolution）    → 85-100%游戏时长
  全部矛盾推向最高点
  最终决战/选择
  结局（要满足"峰终定律"）
```

### 游戏特有的叙事结构

**多结局叙事**：玩家选择影响结局
- 关键：每个结局都要有其"正当性"，没有绝对的好坏结局
- 风险：玩家会攻略最优解，绕过真实的道德选择

**环境叙事（Environmental Storytelling）**：
- 通过场景本身讲故事——焦黑的房间、墙上的照片、遗留的日记
- 玩家自己"发现"的故事比被告知的更有情感重量

**模块化叙事**：
- 主线是强制的，支线是可选的
- 支线要有自己的完整弧线，不是收集任务
- 好的支线甚至比主线更令人难忘

## 5. 对话设计

### 游戏对话的五大原则

1. **服务于玩家行动，而非表演作者学识**
   - 每句话都要推进剧情、透露信息、或建立关系
   - 删掉一切"没有这句话故事也能进行"的对话

2. **人物声音差异化**
   - 不同角色说话方式完全不同——词汇、节奏、习惯用语
   - 遮住角色名字，仍能猜出是谁在说话

3. **次文本（Subtext）**
   - 角色说的和想的不一样
   - "我不在乎" = "我非常在乎"
   - 玩家能读出潜台词时，角色才有深度

4. **对话选项的设计**
   - 不能全是好结果，玩家要面对真实代价
   - 每个选项代表不同的价值观，没有"正确答案"

5. **语音 × 文本的协同**
   - 语音 = 情感传递，文本 = 信息传递
   - 如果有中文配音，要为中文写作，不要翻译腔

## 6. 叙事节奏控制

### 张弛节奏的分类

| 节奏类型 | 特征 | 功能 |
|---------|------|------|
| **动作高潮** | 战斗、逃跑、紧急事件 | 肾上腺素、紧张感 |
| **叙事高潮** | 重大揭示、情感冲突 | 情感峰值 |
| **探索舒缓** | 探索、收集、休息 | 恢复，让玩家消化剧情 |
| **角色时刻** | 伙伴对话、关系建立 | 情感连接，深化角色 |

**节奏编排原则**：高强度段落后必须有舒缓，舒缓才能让下一个高潮更有力。永远拉紧弦只会让玩家麻木。

《最后生还者》著名的长颈鹿场景：在极度紧张的末日叙事中，插入一段平静的动物观赏时刻——正是因为有这段"喘息"，前后的紧张才更有力量。
