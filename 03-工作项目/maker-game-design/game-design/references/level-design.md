# 关卡设计 / 空间引导 / 难度曲线 / 节奏控制

---

## 1. 关卡设计的四维框架

```
┌──────────────────────────────────────────────────┐
│  优秀关卡 = 引导性 × 挑战性 × 探索性 × 叙事性    │
└──────────────────────────────────────────────────┘
```

| 维度 | 目标 | 核心问题 |
|------|------|---------|
| **引导性** | 玩家知道该去哪、该做什么 | 玩家会迷失吗？ |
| **挑战性** | 存在需要克服的有意义障碍 | 心流通道是否维持？ |
| **探索性** | 有值得发现的隐藏内容 | 玩家有动力偏离主路吗？ |
| **叙事性** | 空间本身在讲故事 | 场景是否有记忆点？ |

## 2. 引导设计：无声的指路

### 隐性引导工具

优秀的引导让玩家从不意识到自己被引导，却总走在"对的路"上。

**光线引导**：
- 目标位置更明亮
- 出口处有自然光
- 危险区域光线阴暗

**几何引导**：
- 收缩的走廊指向目标
- 开阔空间暗示可探索区域
- 斜坡和阶梯暗示可交互

**对比引导**：
- 目标颜色与环境形成对比
- 可交互物体材质特殊

**社会引导**：
- NPC 朝向目标方向
- 其他"玩家"（AI）走向目标
- 声音从目标方向传来

**案例**：《超级马里奥》第一关 1-1 的经典设计——游戏从未教过玩家怎么跑跳，但画面构成从左到右、第一只蘑菇的位置，让所有玩家自然向右前进并学会跳跃。

### 引导的边界

- **明确的核心路径**（玩家不会迷失）
- **模糊的探索区域**（让玩家自发发现）
- **错误路径的适当惩罚**（让玩家知道走错了，但不让人放弃）

引导过强 → 游戏成为"走廊"，玩家感觉在看电影
引导过弱 → 玩家迷失沮丧，求助攻略（脱离体验）

## 3. 空间叙事

### 环境叙事技术

空间本身可以讲故事，不依赖任何文字或对话：

**物件叙事**：
- 翻倒的椅子和散落的东西 → 曾经发生过混乱
- 儿童玩具在不该出现的地方 → 曾有孩子在这里
- 两个人的餐具，只用了一边 → 有人离开了

**环境状态叙事**：
- 熄灭的壁炉 vs 燃烧的壁炉 → 场所是否被废弃
- 植物生长 vs 枯萎 → 时间的流逝
- 破损的程度 → 战斗的激烈程度

**视野设计叙事**：
- 看得到远处目标 → 期待感
- 封闭的视野 → 危机感
- 突然开阔的视野 → 震撼（如《旷野之息》从地下走出看到海拉鲁大地）

### 三维空间的心理影响

```
高耸空间（大教堂效果）→ 敬畏感、渺小感
压迫空间（低矮走廊）→ 紧张感、危机感
开阔平原 → 自由感、孤独感
迷宫结构 → 困惑感、探索欲
中心广场 → 安全感、归属感
```

## 4. 关卡序列设计

### Nintendo 三步关卡设计法

任天堂第一方游戏最精华的设计哲学之一：

```
第一步：介绍（Introduction）
  最安全的环境，用最基础的形式展示新机制
  玩家第一次接触，零惩罚探索

第二步：变化（Variation）
  改变上下文：同一机制在不同情景下使用
  增加一点压力：更多元素、更快节奏

第三步：扭曲（Twist）
  颠覆预期：用已学机制做反直觉的事
  制造"啊哈时刻"：玩家感到自己真正掌握了
```

**案例**：《奥德赛》帽子技能 —— 第一次：扔帽子击打开关（介绍）→ 骑乘敌人过障碍（变化）→ 用帽子作为跳台到达原本到不了的地方（扭曲）

### 关卡序列的宏观节奏

```
关卡编号:  L1   L2   L3   L4   L5   Boss  L6...
难度曲线:  ●    ●●   ●●●  ●●  ●●●  ████  ●
                           ↑
                        缓冲关（喘息后继续）
```

每个 Boss 战之后，下一关应该是相对轻松的缓冲——让玩家巩固新学到的技能，再进入新的挑战。

## 5. 开放世界设计

### 有机 vs 格子开放世界

**有机开放世界**（旷野之息、RDR2）：
- 地形设计师手工塑造
- 每个区域有独特性格
- 视觉地标明显

**格子开放世界**（很多手游大地图）：
- 模块化拼接
- 效率高但缺乏惊喜
- 容易产生"千篇一律"感

### 开放世界的密度设计

```
内容密度图：

高密度区（起始区域）：
  密集的 POI（兴趣点）
  短距离内有多个可探索内容
  新手期的"信心建立区"

中密度区（探索中期）：
  POI 间距适中
  鼓励探索的路途

低密度区（远端荒野）：
  空旷但有特殊奖励
  "探索到这里的人值得惊喜"
  营造世界的辽阔感
```

### 标志物（Landmark）设计

开放世界的导航必须依靠视觉标志物，而非只靠地图：

- **大型标志物**（远距离可见）：山峰、高塔、特殊建筑 → 方向锚点
- **中型标志物**（中距离）：独特树木、废墟遗址 → 区域识别
- **小型标志物**（近距离）：特殊地面纹理、声音线索 → 本地导航

## 6. UI/UX 与关卡设计的交叉

### 非侵入式UI设计

关卡体验最大的敌人之一：过于侵入的UI

**好的实践**：
- 《最后生还者》：重要物品在环境中有视觉区分，而非界面标注
- 《死亡搁浅》：疲劳感通过角色动作体现，不是数值条
- 《黑暗之魂》：极简UI，大量信息通过游戏世界本身传达

**手游的特殊挑战**：
- 触摸屏限制精细操作
- 拇指遮挡关键区域
- 横竖屏切换的适配
- 安全操作区（Safe Area）设计必须考虑手持方式

### 屏幕空间的三区划分

```
┌─────────────────────────────────────────────┐
│  危险区（屏幕角落）：容易被遮挡，放次要信息   │
│  ┌─────────────────────────────────────┐    │
│  │  安全区（中部）：核心游戏画面         │   │
│  │  ┌─────────────────────────────┐   │    │
│  │  │  黄金区（视觉中心）：主要     │   │    │
│  │  │  交互和核心信息位置在此       │   │    │
│  │  └─────────────────────────────┘   │    │
│  └─────────────────────────────────────┘    │
└─────────────────────────────────────────────┘
```

## 7. 多人游戏关卡设计特殊性

### 竞技地图的平衡原则

**对称 vs 非对称**：

对称地图：两队起点完全镜像
- 优点：绝对公平，纯技术对抗
- 缺点：视觉单调，策略多样性受限

非对称地图：两侧不同但平衡
- 优点：视觉丰富，攻守体验不同
- 挑战：极难做到真正平衡（需要大量测试）

**关键通道理论**：
```
战略地图通常有3条主路：
  上路 / 中路 / 下路（MOBA的基础）
  主通道 / 侧通道 / 秘道（FPS地图）

中路控制 = 整体态势优势
→ 中路设计要有战略价值，但不能让中路统治一切
```

### 合作关卡的协同设计

好的合作关卡让不同玩家有**互补的作用**，而非简单叠加：

- 需要同时激活两个机关（协作行动）
- 一个玩家掩护，另一个操作（角色分工）
- 信息不对称：玩家A看到玩家B看不到的危险（沟通必要性）

避免：一个玩家无聊等另一个玩家操作，或者所有玩家做完全相同的事。
