# AI 时代的游戏设计

---

## 1. 范式转变概览

生成式 AI 对游戏策划领域的冲击，不只是"工具升级"，而是游戏内容生产方式的根本性转变。

```
工业化时代（人工创作）：
  策划写设计文档 → 美术制作资产 → 程序实现 → QA测试
  时间：6个月 ~ 6年

AI 辅助时代（当前）：
  策划设想 → AI生成初版 → 人工筛选精炼 → 集成
  时间：大幅缩短

AI UGC 时代（正在到来）：
  玩家用自然语言描述 → AI生成游戏内容 → 即时游玩
  代表：Roblox Cube 3D、Epic Games AI工具链
```

## 2. AI 在游戏内容生产中的应用现状

> 📌 实际可用的 AI 工具和完整工作流，详见 [mcp-toolkit.md](mcp-toolkit.md)

AI 已能覆盖游戏内容生产的主要环节：3D 模型、纹理贴图、关卡布局、对话剧情、音效音乐、代码逻辑。当前动画生成仍需人工精修。

### AI NPC 革命

**传统 NPC**：有限的预设对话树，玩家很快发现边界。

**AI NPC（当前可行）**：
- 动态对话：理解上下文，回应玩家自由输入
- 记忆系统：记住玩家的选择和历史
- 性格一致性：基于 prompt 工程维持角色设定

**代表案例**：
- Inworld AI 的 NPC 系统
- 《AI Dungeon》的叙事探索
- Ubisoft NEO NPC（刺客信条新游的AI驱动NPC原型）

**策划的新工作**：从"写每句对话"到"设计角色性格 prompt + 约束规则 + 质量审查"。

## 3. AI 辅助策划工作流

> 📌 具体的工具调用和工作流模板，详见 [mcp-toolkit.md](mcp-toolkit.md)

### 策划提示词工程最佳实践

向 AI 求助游戏设计时，最有效的 prompt 结构：

```
1. 明确游戏类型和目标受众
2. 提供现有设计的约束条件
3. 描述想要解决的具体问题
4. 指定输出格式（数值表/设计文档/系统描述）

示例：
"我在设计一款面向18-25岁的轻度手游，类型是治愈系农场模拟。
核心循环是：种植→浇水→收获→出售→购买新种子。
问题：第7天玩家留存率很低，推测是新鲜感消失。
请生成3个可以在不增加核心复杂度前提下，
在第7天引入新体验的系统方案，每个方案包含：
机制描述、体验目标、实现难度评估（低/中/高）。"
```

## 4. AI 时代策划的不可替代能力

### AI 目前做不到的

1. **真实的文化洞察**：理解当下社会语境中什么会产生共鸣
2. **价值判断**：游戏应该传递什么价值观？什么是边界？
3. **玩家情感的真实感知**：AI 不能"真的玩"游戏并感受
4. **整体体验的编排直觉**："这个瞬间刚好在这里发生"的感觉
5. **原创性的创意跳跃**：真正突破类型边界的设计

### 策划的新核心竞争力

```
传统策划能力（依然重要）：
  系统设计 + 数值平衡 + 关卡设计 + 叙事

新增核心能力：
  ① AI Prompt 工程师：能用 AI 快速生成高质量内容
  ② AI 质量评审员：能识别 AI 内容的问题和边界
  ③ 人机协作流程设计：设计人+AI的协作工作流
  ④ 数据驱动决策：用数据和 AI 分析指导设计迭代
```

## 5. 未来 5 年的游戏设计预判

### 高确定性趋势

1. **AI NPC 普及**：3年内主流3A游戏引入动态AI对话NPC
2. **个性化内容**：游戏根据玩家行为实时调整叙事和难度
3. **创作门槛归零**：手机端语音/文字即可创作游戏内容（Roblox方向）
4. **AI驱动的游戏测试**：AI代替大量人工QA，快速覆盖边缘情况

### 不确定但值得关注

1. **沉浸式AI DM**：AI担任实时"游戏主持人"，生成无限叙事
2. **玩家行为完全建模**：实时预测玩家下一步情绪，先验性调整体验
3. **AIGC版权框架**：AI生成内容的版权归属将重塑整个行业

### 对策划工作的终极影响

> "策划的工作不会消失，但策划的工作内容会发生根本转变：从'制造内容'到'设计生成规则'，从'写每句对话'到'构建角色的灵魂'，从'画每张地图'到'定义世界的法则'。
>
> 这更接近于游戏设计的本质——策划从来都不是内容的生产者，而是规则的构建者和体验的编排者。AI 工具的普及，反而让这个本质更加清晰。"
