# 玩家心理与动机深度参考

> 游戏策划本质上是在研究人。理解玩家为什么玩、为什么留、为什么离开，是一切设计决策的基础。

---

## 1. 玩家动机的多层次模型

### 基础动机金字塔

```
            峰值体验
           （自我实现）
          ────────────
         掌握感 · 成就感
        ──────────────────
       社会认同 · 归属连接
      ────────────────────────
     安全感 · 可预期的奖励结构
    ──────────────────────────────
   感官刺激 · 即时反馈 · 基础乐趣
```

底层需求未满足，上层的精心设计都是浪费。玩家连基础操作手感都不舒适，再好的叙事也留不住他们。

### 玩家游戏的六种根本原因

1. **逃避**：现实压力的出口，游戏提供另一个世界
2. **控制感**：在现实中无力，在游戏中掌控一切
3. **成就感**：获得在现实中难以获得的成功体验
4. **社交连接**：维持关系、寻找同伴
5. **探索与好奇**：人类天生的发现欲
6. **自我表达**：展示个性、创造属于自己的东西

**设计含义**：每款游戏主要服务于其中的1-2种根本动机。设计决策偏离主动机时往往出问题。

## 2. 情感体验设计

### 情感弧线（Emotional Arc）

玩家记住的不是功能列表，而是情感体验的峰值与终点。

根据"峰终定律"（Peak-End Rule，Kahneman）：人们对体验的记忆主要由**峰值瞬间**和**结束时的状态**决定，而非体验的平均值。

```
情感强度
  ↑
  │                    ★ 峰值（Boss战胜利 / 重大剧情）
  │         ★ 小峰值         ★ 小峰值
  │    ★  ×  ×    ★   ×  ×         ★ 终点
  │  × × × × × × × × × × × × × × ×
  └────────────────────────────────→ 游戏进程
     ↑
  × = 平凡时刻（大多数时间）
  ★ = 设计应着力的峰值时刻
```

**设计启示**：
- 不必让每一分钟都精彩，但峰值时刻必须精心设计
- 游戏结局（终点）的体验比过程更影响玩家是否会推荐游戏
- 差体验的"峰值"（极度沮丧的时刻）同样会被记住——要避免

### 情感类型与设计手法

| 目标情感 | 触发机制 | 设计注意 |
|---------|---------|---------|
| **惊喜** | 打破预期、隐藏内容、随机涌现 | 惊喜要"意外但合理"，不能觉得作弊 |
| **恐惧** | 未知、资源稀缺、时间压力 | 恐惧之后要有解脱，否则变焦虑 |
| **自豪** | 克服真实挑战、技巧被认可 | 成就必须是真实努力的结果 |
| **好奇** | 不完整信息、隐约可见的目标 | 永远不要一次性满足好奇心 |
| **归属** | 共同目标、互相依赖、共享历史 | 社交系统要降低进入门槛 |
| **掌控** | 复杂系统被玩家理解和操纵 | 复杂度要有层次，不能一下全压 |

## 3. 认知偏误与游戏设计

了解这些认知偏误，既是为了有效设计，也是为了不去恶意利用它们。

### 损失厌恶（Loss Aversion）
- 失去100元的痛苦 ≈ 获得200元的快乐
- **设计应用**：限时活动、濒死状态提示、"你快要完成了"的进度条
- **滥用警告**：用于逼迫玩家付费（"不氪金就要失去XXX"）是破坏信任的设计

### 禀赋效应（Endowment Effect）
- 拥有的东西，主观价值远高于客观价值
- **设计应用**：个性化装扮、玩家命名的道具、创意建造
- **案例**：《动森》的岛屿名字、装扮，让玩家极难离开

### 沉没成本谬误（Sunk Cost Fallacy）
- 已经投入的时间/金钱，成为继续投入的理由
- **设计应用（慎用）**：积累型成长系统、长期投入的角色养成
- **滥用警告**：用于绑架玩家（"你已经投入这么多了"），这是不健康的留存

### 可变奖励（Variable Reward）
- 不确定的奖励比固定奖励更能刺激多巴胺
- **设计应用**：Loot Box、随机掉落、探索未知区域
- **边界**：可变奖励本身不是问题，问题在于是否对概率不透明、是否面向未成年人

### 蔡加尼克效应（Zeigarnik Effect）
- 未完成的任务比完成的任务更占据心理空间
- **设计应用**：进度条、待完成的支线、悬而未决的剧情
- **案例**：大多数手游的每日任务列表

### 社会比较（Social Comparison）
- 人类本能地与他人比较自己
- **设计应用**：排行榜、好友进度显示、成就展示
- **注意**：向上比较（比你强的人）激励动力，过于压制则带来挫败感

## 4. 玩家行为生命周期

### 五阶段模型

```
新手期          成长期         核心期          精英期         衰退期
Discovery   →  Learning  →   Mastery   →   Expertise  →   Decline
(0-3小时)      (3-30小时)    (30-300小时)   (300+小时)     (倦怠期)

关键体验：      关键体验：      关键体验：      关键体验：      关键体验：
第一次有趣      持续成长感      掌控的自豪      证明自我        寻找新刺激

设计重心：      设计重心：      设计重心：      设计重心：      设计重心：
降低门槛        清晰反馈        深度内容        竞技/极限玩法   社交/传承
无惩罚探索      可见的进步      Build多样性     排名系统        新手引导新人
```

### 玩家流失的关键节点

| 节点 | 原因 | 预防设计 |
|------|------|---------|
| **前30分钟** | 不知道怎么玩 / 不好玩 | 引导设计、核心循环极简化 |
| **第1天结束** | 无法看到长期目标 | 展示游戏深度、给出"钩子" |
| **第7天** | 新鲜感褪去、没有新内容 | 二级系统解锁、社交引入 |
| **第30天** | 目标枯竭、重复感 | 内容更新节奏、PVP引入 |
| **好友离开** | 社交锚点消失 | 降低重返门槛、公会系统 |

## 5. 不同年龄段玩家心理

### 各年龄段核心需求

| 年龄段 | 核心需求 | 设计偏好 | 注意事项 |
|-------|---------|---------|---------|
| **<12岁** | 探索、幻想、简单成就感 | 颜色鲜艳、规则简单、零惩罚 | 无法理解复杂概率；付费保护 |
| **13-17岁** | 社交认同、竞争证明、身份建构 | PVP、社交、个性化 | 易受同伴压力；保护心理健康 |
| **18-25岁** | 竞技深度、社交娱乐、逃避压力 | 高上限技巧、深度叙事 | 时间最多，付费最少 |
| **26-35岁** | 效率感、有限时间的满足感 | 会话式游戏、清晰进度 | 碎片化时间；最高付费意愿 |
| **35岁+** | 怀旧、故事、放松 | 低压力、叙事导向、经典玩法 | 不接受复杂新手引导 |

## 6. 玩家心理健康与设计责任

作为策划，对玩家心理健康负有责任：

### 健康的游戏设计
- 允许玩家随时退出（会话长度可控）
- 失败惩罚合理，不激起极端情绪
- 社交系统正向（不鼓励欺凌、排外）
- 付费机制透明

### 需要警惕的设计模式
- **制造焦虑**：倒计时、濒临失去的感受 → 短期留存，长期伤害
- **强制社交**：体力、战令等绑架玩家 → 产生义务感而非乐趣
- **操纵性随机**：不透明的概率、诱导性的"差一点"（near-miss）
- **孤独感放大**：通过展示他人进度让玩家感到落后

> 长期主义的游戏策划明白：**玩家的信任比今日的营收更值钱。**一款让玩家感到被尊重的游戏，其生命周期是那些消耗玩家的游戏的数倍。
