# diagrams

> **English TL;DR:** A structured personal knowledge workspace — an identity/agent-config archive (IDENTITY / USER / SOUL), Anthropic↔OpenClaw skill-migration records, categorized document folders, and an ASR audio-transcription test script (`asr_test.py`).

> 结构化个人知识工作区：文档、ASR 音频转写工具与 Agent 技能迁移档案。

## 📖 项目简介

一个多用途的工作知识库/工具区，既是技能迁移与身份档案的存放地，也包含文档目录与音频转写脚本（`asr_test.py`）。

## 🗂️ 内容地图

### 顶层文档（身份与 Agent 配置）
| 文件 | 作用 |
|------|------|
| `IDENTITY.md` | 个人身份定义（如 Agent 人格名「小 Cl」） |
| `USER.md` / `TOOLS.md` / `SOUL.md` | 用户 / 工具 / 人格档案 |
| `INDEX.md` / `HEARTBEAT.md` | 索引与心跳状态 |
| `AGENTS.md` | Agent 协作约定 |

### Agent Skills 迁移档案

- `Anthropic Skills 迁移到 OpenClaw 指南.md`
- `Anthropic Skills 迁移总结.md` / `Anthropic 官方 Skills 清单.md`
- `OpenClaw Skills 迁移状态.md`
- `Superpowers Skill 安装报告.md`

### 分类目录

```text
03-工作项目 / 04-实验测试 / 05-学习文档 / 06-工具脚本 / 99-归档
docs/  memory/
```

### 脚本

- `tools/`：工具脚本
- `asr_test.py`：音频转写（ASR）测试脚本

## 🚀 使用

```bash
ls 05-学习文档          # 浏览学习文档
python asr_test.py      # 运行音频转写测试（如已配置 ASR 环境）
```

## 📌 定位

知识管理 + Agent 配置档案 + 技能迁移记录的工作区，重在沉淀与复用。
