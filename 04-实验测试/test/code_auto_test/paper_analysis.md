# TITAN 框架通俗拆解
它就是一个**用GPT-4o驱动、不用专门训练、能测各种网游**的自动测试工具，模仿真人测试员的思路，一圈循环干活，核心就4个模块：

---

## 1. 感知抽象模块 = 帮AI「看懂并精简游戏」
游戏里信息太杂（坐标、血量、NPC、道具、天气…），AI看不过来。
- 它**删掉没用的信息**
- 把复杂数字变成简单文字（比如血量：高/中/低）
- 给AI喂**干净、简短**的信息
- 换个游戏也能快速适配

一句话：**帮AI“读明白”游戏，还不累。**

---

## 2. 动作优化模块 = 帮AI「只做有用的操作」
网游里能点的动作超多（走、打、对话、用道具…），90%都是瞎操作。
- 定好通用动作模板（移动、对话、攻击、使用道具等）
- 结合游戏经验，**只推荐5个左右当前最该做的动作**
- 过滤无效、乱点的操作
- 确认动作能执行才让AI去点

一句话：**不让AI瞎点，只做对测试有用的事。**

---

## 3. 反射推理模块 = 框架核心，帮AI「会思考、会卡关自救」
就像人玩游戏卡关了会回头想办法。
- **进度监控**：一直看任务有没有推进，一直没进展就判定“卡关”
- **反思复盘**：回看之前的操作，分析错在哪，换策略
- **记住测过的地方**：不再重复瞎测，既完成任务，又去没测过的地方找bug

一句话：**AI不会死磕卡死，会自己改方法，长任务也能搞定。**

---

## 4. 问题诊断模块 = 帮AI「自动找bug、写报告」
专门负责抓问题，有3个“监控眼”：
1. **崩溃监控**：游戏一崩立刻抓住
2. **任务卡死监控**：任务一直不动，标记bug并写清楚原因
3. **执行时间监控**：动作/任务太慢（无限循环、服务器卡）也能发现
- 整体误报率：30%

一句话：**自动抓bug、自动写报告，不用人盯着。**

---

# 整体流程（超简版）
1. 先**看懂精简游戏**（感知抽象）
2. 再**挑对有用动作**（动作优化）
3. 卡关**会思考改策略**（反射推理）
4. 找到问题**自动报bug**（问题诊断）

全程循环，自动帮你测网游。
