## 第一步：理解这个项目是什么

这个项目模拟了一个**虚构的封闭小镇**的经济运转。你可以把它想象成一个棋盘游戏：

- 每个"棋子"（Agent）都有自己的规则和目标
- 每过一个月，所有棋子按顺序行动
- 我们观察多年后整个小镇经济的变化

**核心问题：** 如果银行提高贷款利率，工人的工资会涨还是跌？工厂会不会破产？

---

## 第二步：理解五个经济主体

### 🏦 银行（Bank）

银行是小镇的"血液泵"。

**它做什么：**
- 吸收存款：工人把工资存进来，银行每月付利息
- 发放贷款：工厂借钱去生产，银行收取更高的利息
- **利润 = 贷款利息收入 - 存款利息支出**

**它的烦恼：**
- 如果工厂赚不到钱，还不上贷款，银行就有"坏账"
- 如果坏账太多，银行自己也会危机

**代码位置：** `agents/bank.py`

```python
# 银行最核心的逻辑：调整利率
def update_rates(self):
    if liquidity_ratio > 0.5:      # 钱太多没人借
        self.deposit_rate -= 0.002  # 少付储户利息
        self.loan_rate    -= 0.001  # 降价吸引工厂贷款
    elif liquidity_ratio < 0.25:   # 钱快不够用了
        self.deposit_rate += 0.003  # 多给利息吸引存款
        self.loan_rate    += 0.002  # 提价保护自己
```

---

### 🏭 工厂主（FactoryOwner）

工厂主是小镇的"引擎"，把借来的钱和工人的劳动转化为商品。

**它做什么：**
1. 向银行借钱（贷款）
2. 用钱雇工人（出价略高于工人的最低期望工资）
3. 工人劳动产出商品
4. 卖给外部市场，收回资金
5. 还贷款，剩下的是利润

**生产公式（柯布-道格拉斯）：**
```
产量 Q = 技术系数 × 资本投入^0.4 × 劳动力^0.4
```

简单理解：钱越多、工人越多、技术越好 → 产量越高，但增速会递减。

**代码位置：** `agents/factory.py`

**三个工厂的差异：**
| 工厂 | 技术系数 | 特点 |
|------|---------|------|
| 厂A | 1.2（最高）| 技术强，同等投入产量最多 |
| 厂B | 1.0（中等）| 均衡型 |
| 厂C | 0.8（最低）| 资本充足型，更依赖钱而不是技术 |

---

### 👷 工人（Worker）

工人是小镇的"多数人"，他们的行为决定了储蓄率和消费结构。

**它做什么：**
- 寻找工作：比较各工厂的工资，接受 ≥ 心理工资的邀约
- 收到工资后：一部分存银行，一部分消费（60% 本地，40% 流出镇外）
- 失业时：心理工资预期每月降低 2%（最多降到初始的 50%）

**工人异质性**（每个工人初始化时随机确定）：
| 属性 | 范围 | 影响 |
|------|------|------|
| 技能水平 | 0.5~1.5 | 对工厂产量的贡献，决定被优先雇佣 |
| 储蓄倾向 | 10%~40% | 存多少钱进银行 |
| 心理工资 | 50~120 | 最低可接受的月工资 |
| 本地消费比 | 40%~80% | 多少消费流向本地零售商 |

**代码位置：** `agents/worker.py`

---

### 🛒 零售商（Retailer）

零售商是资金在镇内循环的"阀门"。

**它做什么：**
- 接收工人的本地消费支出
- 留下 10% 作为利润（存入银行）
- 其余 90% 支付给外部供应商（资金流出镇外）

零售商存在的意义：如果没有零售商，工人所有消费都流出镇外，小镇经济会更快失血。

**代码位置：** `agents/retailer.py`

---

### 🌍 外部市场（ExternalMarket）

外部市场是小镇唯一的"收入来源"，工厂把商品卖到这里换回资金。

**需求规律：**
- 价格越低，卖得越多（价格弹性 = 1.5）
- 外部经济景气时需求高，萧条时需求低（随机游走模拟）

**代码位置：** `agents/external_market.py`

## 第三步：理解月度循环

每个月按以下顺序发生（`core/simulation.py`）：

```
月初
  ↓
① 银行根据流动性调整利率
  ↓
② 工厂评估上月利润 → 决定借多少钱
  ↓
③ 劳动力市场：工厂出价，工人决定是否接受
  ↓
④ 生产：Q = A × K^α × L^β
  ↓
⑤ 外部市场景气随机变化 → 工厂按需调价 → 销售
  ↓
⑥ 发工资（工厂现金减少，工人现金增加）
  ↓
⑦ 工人：储蓄进银行 + 本地消费进零售商
  ↓
⑧ 工厂：还贷款（还不上 → 坏账）
  ↓
⑨ 零售商：利润存银行，进货成本流出镇外
  ↓
⑩ 银行：支付存款利息，记录坏账
月末
```

## 第四步：理解关键经济指标

运行仿真后，你会看到这些指标，它们的含义：

| 指标 | 好的方向 | 坏的方向 |
|------|---------|---------|
| **就业率** | 接近 100% | 持续下降 |
| **平均工资** | 稳步上升 | 停滞或下降 |
| **基尼系数** | 接近 0（平等）| 接近 1（悬殊）|
| **银行坏账率** | 接近 0% | 超过 20%（危险）|
| **净外部流入** | 正数（顺差）| 负数（逆差）|
| **工厂利润率** | 正数且稳定 | 持续为负 |

## 第七步：常见问题

**Q: 为什么就业率有时会忽高忽低？**

月初所有工人重新进入劳动力市场，各工厂重新抢人。如果某月工厂资金不足（比如上月亏损，不敢多借款），出价的工资可能低于部分工人的心理工资，导致就业率下降。

**Q: 银行的钱从哪里来？**

银行初始有自有资本（`BANK_INITIAL_CAPITAL = 30000`），加上工人和零售商的存款。工厂还款的利息是银行的收入。

**Q: 工厂破产后能复活吗？**

不能。破产后 `is_bankrupt = True`，该工厂退出仿真，劳动力市场和信贷市场的压力会减少，可能让其他工厂恢复。

**Q: LLM 分析准确吗？**

LLM（qwen2.5:0.5b）的分析是基于提示词中的数据生成的，定性分析有参考价值，但不要把它当成精确预测。它的主要作用是帮你用自然语言理解数字背后的逻辑。

**Q: 为什么不用更大的模型？**

选 0.5b 是为了速度——每次分析只需 1~3 秒，不阻塞仿真。如果你需要更深入的分析，可以修改 `config/params.py` 中的 `OLLAMA_MODEL = "qwen2.5:7b"` 并提前 `ollama pull qwen2.5:7b`。

| 方向 | 难度 | 说明 |
|------|------|------|
| 增加政府/税收 | ⭐⭐ | 新增 Government Agent，向工厂和工人征税，用于公共投资 |
