# 系统架构详解

## 1. 整体架构

系统分为三层：

```
┌─────────────────────────────────────────────────────────┐
│                    main.py（入口层）                      │
│   解析参数 → 创建 TownEconomy → 运行 N 月 → 输出报告      │
└────────────────────────┬────────────────────────────────┘
                         │
┌────────────────────────▼────────────────────────────────┐
│              core/simulation.py（协调层）                 │
│                                                          │
│   每月按顺序驱动所有 Agent 完成：                          │
│   银行调利率 → 工厂借贷 → 劳动力市场 → 生产 → 销售        │
│   → 发工资 → 工人收支 → 工厂结算 → 零售商结算 → 银行结算   │
└──────┬──────────┬──────────┬───────────┬────────────────┘
       │          │          │           │
┌──────▼──┐  ┌───▼────┐  ┌──▼─────┐  ┌──▼──────────┐
│  Bank   │  │Factory │  │ Worker │  │  Retailer   │
```

## 2. 月度仿真循环（10 个阶段）

每次调用 `TownEconomy.step()` 执行以下顺序：

```
Phase 1  银行调整利率
         └─ 规则：流动性充裕→降利率，流动性紧张→升利率

Phase 2  工厂申请贷款
         └─ 根据上月利润决定扩张/收缩规模

Phase 3  劳动力市场匹配
         ├─ 所有工人先"离职"（月度重匹配机制）
         ├─ 工厂按技术系数从高到低排队抢人
         └─ 工人按工资水平决定是否接受（心理工资会随失业时间降低）

Phase 4  生产
         └─ Q = A × K^α × L^β（柯布-道格拉斯生产函数）

Phase 5  外部市场需求更新 + 销售
         ├─ 需求冲击随机游走（均值回归）
         ├─ 工厂根据上月滞销率自动调价（±3%~5%）
         └─ 实际销量 = min(产量, 市场需求量)

Phase 6  发工资
         └─ 从现金中扣除，工人收入确定

Phase 7  工人月度收支
         ├─ 储蓄部分 → 存入银行
         └─ 消费部分 → 60%本地零售商，40%流出镇外

Phase 8  工厂还贷 + 月末结算
         ├─ 还不上则产生坏账（银行资本金减少）
         └─ 记录本月快照到 history

Phase 9  零售商结算
         └─ 利润(10%)存入银行，进货成本流出镇外

Phase 10 银行月末结算
         ├─ 向所有储户支付存款利息
         └─ 记录快照
```

## 3. 资金流动完整路径

```
外部市场
    │
    │ ① 工厂销售收入（Q × P，受需求曲线约束）
    ▼
工厂现金池
    │                        ┌─────────────────┐
    ├──② 发工资────────────▶│   工人现金       │
    │                        └────┬────────────┘
    └──③ 还贷款利息──────────▶银行                │
              （本金归还银行    利润留存银行）      │ ④ 储蓄（工资×储蓄率）
                                  ▲               ▼
                                  │ ⑤ 存款利息  银行存款池
                                  │               │
                              ⑥ 贷款             │ ⑦ 本地消费（储蓄后剩余×60%）
                              (新一轮)            ▼
                                            零售商
                                              │ ⑧ 利润(10%)存银行
                                              │ ⑨ 进货成本(90%)→流出镇外
                                              ▼
                                           外部供应商
```

**资金净流入 = ① - ⑨**（工厂出口收入 - 零售商进口成本）

## 4. Agent 状态机

### 工人状态机
```
               ┌──────────────┐
               │    待业       │◀─────────────┐
               │(失业计数器+1)│               │
               └──────┬───────┘               │ 被裁/月初释放
                      │ 接受工作邀约            │
                 (工资 ≥ 心理工资)             │
                      ▼                        │
               ┌──────────────┐               │
               │    在职       │───────────────┘
               │(收工资+消费)  │
               └──────────────┘

 心理工资 = 初始心理工资 × max(0.5, 1 - 0.02 × 失业月数)
 （失业越久越愿意接受低工资，但最低降到初始的 50%）
```

### 工厂状态机
```
               ┌──────────────────────┐
               │   正常运营            │
               │ profit>0 → 扩张借贷  │
               │ profit<0 → 收缩借贷  │
               └───────────┬──────────┘
                           │ 现金 < 0 且还款率 < 50%
                           ▼
               ┌──────────────────────┐
               │      破产            │
               │  停止生产和雇工       │
               │  坏账计入银行         │
               └──────────────────────┘
```

## 5. 银行利率调整规则

```python
流动性比率 = (存款 + 资本 - 贷款总额) / 存款

if 流动性比率 > 0.5:      # 资金充裕
    存款利率 -= 0.002     # 降低揽储成本
    贷款利率 -= 0.001     # 吸引贷款需求

elif 流动性比率 < 0.25:   # 资金紧张（准备金率20% + 5%缓冲）
    存款利率 += 0.003     # 提高揽储
    贷款利率 += 0.002     # 控制风险

# 利率边界
存款利率: [0.5%, 8%]
贷款利率: [2%, 15%]
```

## 6. 外部市场需求模型

需求曲线（每个工厂独立）：
```
Q_demand = Q_base × (P_base / P)^ε × shock_t

参数含义：
  Q_base = 500 × uniform(0.8, 1.2)  # 各工厂基准需求（略有差异）
  P_base = 10.0                      # 基准价格
  ε      = 1.5                       # 价格弹性（>1 表示富有弹性）
  shock  = 随机游走（均值回归到 1.0，月波动率 10%）
```

工厂定价策略：
```
上月滞销率 < 80%  → 降价 5%（去库存）
上月滞销率 > 95%  → 提价 3%（需求旺盛）
其他              → 保持价格
价格范围：[5.0, 20.0]
```

## 7. LLM 分析层架构

```
规则引擎层（每月，毫秒级）           LLM 分析层（按需，秒级）
─────────────────────────           ─────────────────────────
所有 Agent 决策                      年度报告（每 12 个月）
经济数值计算                   →     异常预警分析（失业率>30%等）
统计指标汇总                         工人生活叙述
                                      ↓
                             ollama HTTP API
                             （localhost:11434）
                                      ↓
                             qwen2.5:0.5b（本地，无网络）
```

Prompt 设计原则：
- 给 LLM 结构化数据，要求输出自然语言解读
- 明确限定字数（300 字以内），避免冗余
- 要求输出包含"原因分析 + 建议"，有实际价值
