# 封闭小镇经济体分析

> 版本 v0.2 — 已根据用户确认更新

---

## 一、经济体概览

这是一个**半封闭**的小镇经济体：
- **内部循环**：银行 ↔ 工厂主 ↔ 工人 ↔ 本地零售商 相互流转
- **外部输入**：工厂产品出口到外部市场，换取外部资金流入
- **资金漏出**：工人部分消费购买外部商品（经由零售商进口）

### 确认规模
| 主体 | 数量 |
|------|------|
| 银行 | 1 个 |
| 工厂主 | 3 个（相互竞争劳动力和市场） |
| 工人 | 30 个 |
| 本地零售商 | 1~3 个 |
| 外部市场 | 虚拟（需求曲线建模） |

## 二、经济主体（Agents）详细定义

### 1. 银行（Bank Agent）× 1

**资产负债表：**
```
资产端：           负债端：
- 贷款总额 L       - 存款总额 D
- 准备金 R         - 自有资本 E
```

**决策逻辑（规则引擎）：**
- 每月根据流动性比率 `R/D` 调整利率：
  - 流动性充裕（R/D > 阈值）→ 下调存款利率，刺激贷款需求
  - 流动性紧张（R/D < 阈值）→ 上调存款利率，吸引存款
- 贷款审批：审查工厂主的还款能力（上期利润 / 贷款申请额）
- 坏账处理：工厂违约时，核销部分资产，影响自有资本

**关键参数：**
| 参数 | 初始值建议 | 说明 |
|------|-----------|------|
| `r_deposit` | 2% / 月 | 存款月利率 |
| `r_loan` | 5% / 月 | 贷款月利率 |
| `reserve_ratio` | 20% | 最低准备金率 |
| `max_loan_per_factory` | 500 | 单个工厂最大贷款额 |

---

### 2. 工厂主（FactoryOwner Agent）× 3

**每月决策流程：**
```
1. 评估上月利润 → 决定本月生产规模目标
2. 根据目标计算资金缺口 → 向银行申请贷款
3. 在劳动力市场竞价 → 决定工资、雇佣工人数
4. 组织生产 → 输出商品
5. 向外部市场定价销售（需求曲线决定销量）
6. 收回销售额 → 还贷款 → 剩余为利润/亏损
```

**生产函数（柯布-道格拉斯简化版）：**
```
Q = A × K^α × L^β
```
- `Q`: 产出数量
- `A`: 技术系数（工厂固有效率，各厂不同）
- `K`: 资本投入（贷款额）
- `L`: 劳动力投入（雇佣工人数）
- `α + β ≤ 1`（规模报酬递减或不变）

**工厂间差异（初始化时随机分配）：**
| | 工厂A | 工厂B | 工厂C |
|-|------|------|------|
| 技术系数A | 1.2 | 1.0 | 0.8 |
| 资本偏好α | 0.4 | 0.5 | 0.3 |
| 劳动偏好β | 0.4 | 0.3 | 0.5 |
| 初始资本 | 小 | 中 | 大 |

---

### 3. 工人（Worker Agent）× 30

**状态机：**
```
[待业] → 接受雇佣 → [在职] → 被裁员/主动离职 → [待业]
```

**每月决策：**
- **在职时**：收到工资 → 决定储蓄率 → 消费剩余部分
- **待业时**：寻找工作（比较各工厂工资）→ 降低心理工资预期（失业越久越低）
- **消费分配**：
  - 本地零售商消费比例 `local_spend_ratio`（默认 60%）
  - 外部商品消费（剩余 40%，流出镇外）

**工人异质性（初始化随机）：**
| 属性 | 范围 | 说明 |
|------|------|------|
| `skill_level` | 0.5 ~ 1.5 | 技能水平，影响生产贡献 |
| `savings_preference` | 0.1 ~ 0.4 | 储蓄倾向 |
| `reservation_wage` | 50 ~ 150 | 最低心理工资 |
| `local_spend_ratio` | 0.4 ~ 0.8 | 在本地消费比例 |

---

### 4. 本地零售商（Retailer Agent）× 1~3

**职能：**
- 从外部采购商品，加价卖给本地工人
- 收到工人的本地消费支出
- 部分资金作为利润留存，部分用于进货（向外支付）

**简化建模：**
- 零售商不做复杂决策，只作为**资金中转节点**
- 每月：收入 = 工人本地消费总额；利润 = 收入 × 零售利润率（10%）；其余支付给外部供应商

> 可选：后期让零售商也把利润存银行、向银行借款扩张

---

### 5. 外部市场（External Market）— 虚拟节点

**需求曲线建模：**
```
Q_demand = Q_base × (P_base / P)^ε × shock_t
```
- `Q_base`: 基础需求量（外部市场对小镇产品的基准需求）
- `P_base`: 基准价格
- `P`: 工厂实际定价
- `ε`: 价格弹性系数（ε > 1 表示需求富有弹性）
- `shock_t`: 外部需求冲击因子（随机游走，模拟经济周期）

**多厂竞争外部市场：**
- 三个工厂的产品假设可以**差异化**（略有差别），各自有独立需求曲线
- 或者**同质化**竞争：价格低的工厂抢更多份额（价格战）

## 四、时间步设计（月度循环）

```python
# 每月执行顺序
def monthly_step(t):
    # Phase 1: 银行公布利率（规则引擎）
    bank.update_rates()

    # Phase 2: 工厂主制定计划（规则引擎）
    for factory in factories:
        factory.plan_production()      # 决定目标产量
        factory.apply_for_loan(bank)   # 申请贷款
        factory.hire_workers(workers)  # 在劳动力市场竞价

    # Phase 3: 生产执行
    for factory in factories:
        factory.produce()              # Q = A·K^α·L^β

    # Phase 4: 外部市场销售
    for factory in factories:
        factory.sell_to_market(external_market)

    # Phase 5: 工厂财务结算
    for factory in factories:
        factory.repay_loan(bank)
        factory.calculate_profit()

    # Phase 6: 工人收支
    for worker in workers:
        worker.receive_wage()
        worker.deposit_savings(bank)
        worker.consume(retailers)

    # Phase 7: 零售商结算
    for retailer in retailers:
        retailer.settle()

    # Phase 8: 银行结算（坏账处理）
    bank.settle()
    bank.handle_bad_debt()

    # Phase 9: 统计 & LLM分析
    stats = collect_statistics()
    if t % 12 == 0:  # 每年做一次LLM深度分析
        llm_analyst.analyze(stats)
```

## 五、关键指标统计系统

### 实时指标（每月）
| 指标 | 公式 | 意义 |
|------|------|------|
| 就业率 | `在职工人数 / 30` | 劳动力市场 |
| 平均工资 | `工资总额 / 在职工人数` | 工人生活水平 |
| 工厂平均利润率 | `Σ(利润/收入) / 3` | 实体经济活力 |
| 银行利差 | `r_loan - r_deposit` | 金融盈利能力 |
| 银行坏账率 | `坏账余额 / 总贷款` | 金融风险 |
| 镇内货币流量 | `工资总额 + 存款利息` | 内部循环强度 |
| 外部资金净流入 | `销售收入 - 进货成本` | 贸易顺差 |

### 周期指标（每年）
| 指标 | 说明 |
|------|------|
| 基尼系数 | 所有主体财富分布不平等程度 |
| 银行总资产增速 | 金融扩张速度 |
| 工厂市场份额变化 | 竞争格局演变 |
| 实际工资增速 | 工人福利改善速度 |

## 六、LLM 分析层设计（混合架构）

### 角色分工
```
规则引擎层（每月运行，快速）：
  - 所有 agent 的经济决策
  - 生产、雇佣、定价、还贷等数值计算

LLM 分析层（按需调用，慢但深刻）：
  - 年度经济报告撰写
  - 异常事件解释（如：本月失业率骤升原因分析）
  - 政策模拟建议（如：银行应该降息吗？）
  - 经济主体视角叙述（工人小明这个月的生活状况）
```

### LLM 调用时机
1. **每12个月**：生成年度经济分析报告
2. **触发式**：出现异常指标时（失业率 > 30%，银行坏账率 > 20% 等）
3. **用户查询**：用户对某个指标或事件进行提问时

### LLM Prompt 结构（示例）
```
你是小镇经济分析师。以下是本月经济数据：
- 就业率：67%（上月：80%）
- 平均工资：120（上月：140）
- 银行贷款利率：7%（上月：5%）
- 工厂B本月亏损并申请破产

请分析：
1. 本次就业率下滑的根本原因链
2. 银行提高利率的时机是否合理
3. 对工人群体的实际影响
4. 接下来1-3个月的经济走势预测
```
